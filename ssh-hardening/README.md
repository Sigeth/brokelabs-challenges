# SSH hardening

A beginner **Linux hardening** challenge for [opslab](https://github.com/Sigeth) (working name): an `sshd` that lets root in with a key and accepts weak passwords.

- Runtime: one `vm` machine, the opslab-images Debian 13 base as is; `setup/setup.sh` breaks it
- Checks: `sshLogin` only (real logins from outside the machine)
- Solution: `solution/solve.sh`
